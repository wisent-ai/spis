## Recurring patterns

Across the 50 records, first success consistently crosses six observable phases: stable entry context, task invocation, target selection, configuration, commit, and visible result. Persistent navigation retains application context while the central working surface changes. Selection feedback precedes destructive or consequential commit actions, and first-success evidence is strongest when the result replaces or augments the in-progress surface rather than relying on a transient toast.

The products also repeatedly separate immediate control feedback from task-dependent operation feedback. Direct selection and navigation react without a perceptible wait, while deployment, query, import, send, save, and report operations expose a later result state. This distinction is visible in each local recording and is represented in the interaction and motion sections of every record.

## Disagreements across products

The records do not support one universal navigation or confirmation model. Communication and support products favor list/detail continuity; design and canvas products retain tool context around a mutable surface; developer and data products foreground run/deploy/query transitions; finance and commerce products add explicit review or commit boundaries. Backtracking is correspondingly cheap before commit in some products and constrained after commit in operational products.

Feedback placement also varies. Some products update the working canvas in place, some reveal a dedicated detail/result surface, and others preserve the prior context while adding status. The per-product state frames should therefore be used before borrowing a transition pattern.

## Applicability boundaries

These references document the web surfaces and official workflows visible in the retained upstream-owner recordings on 2026-08-16. They do not establish screen-reader semantics, exhaustive keyboard focus order, reduced-motion preference handling, enterprise-only permissions, authentication setup, or every error class. Those unknowns remain explicit in each record. Use the synthesis for cross-product comparison; use the numbered product record and local media for implementation-level evidence.
