# Content and Takedown Policy

This repository hosts a reference corpus of third-party product interfaces: verbatim README snapshots, screenshots, recordings, and measured metadata, each with recorded source, hashes, and provenance class.

## Provenance classes

Every record states how its media was obtained:

- `local-product-run` — captured by running the product on our infrastructure;
- `local-browser-run` — captured through a browser we drove on a Stado-selected host;
- `upstream-owner-media` — media published by the product's owner, stored with its source URL.

## Rights

We claim no ownership over third-party content. Upstream README snapshots retain their original license terms, recorded per source in `sources.json`. Media is hosted for reference and research; it is never presented as Wisent's own work.

## Takedowns

If you own content in this corpus and want it removed or relinked:

1. Open an issue titled `takedown: <catalog>/<record>` (a private security advisory also works), or email the contact on the repository owner's profile.
2. Include the record path or enough detail to identify it.
3. We will remove or relink the media and confirm in the issue.

Removal is honored for any reason; you do not need to state a legal basis.
